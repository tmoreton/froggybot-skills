# X / Twitter Research

Use X as a source of timely public conversation, not as unquestioned ground truth.

1. Translate the user's question into a focused search query. Use `from:`, quotes, hashtags, exclusions, and `-is:retweet` when they improve signal.
2. Search narrowly first and broaden only when results are sparse.
3. Distinguish eyewitness or first-party posts from commentary and repetition.
4. Include author, date, engagement context, and a direct post URL for evidence you rely on.
5. Group repeated claims rather than treating reposts as independent confirmation.
6. Clearly label sentiment, trend, and consensus conclusions as analysis.

This skill is read-only. Never claim to post, like, follow, or message on the user's behalf.
